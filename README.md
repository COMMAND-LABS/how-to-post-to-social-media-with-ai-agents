# TLDR

Accompanying repo for the "How to post to Social Media with AI Agents" video.

## Gist of how this system works

- Compile Social Media Content
- Review (Human-in-the-Loop)
- Schedule
- Review (Human-in-the-Loop)
- Publish

## System components

- PART 1: Airtable (https://airtable.com/)
- PART 2: Claude (https://claude.com/download)
- PART 3: Cloud Storage
  - OPTION A: Google Cloud Storage (https://console.cloud.google.com/storage) [recommended]
  - OPTION B: Dropbox (https://www.dropbox.com/)
- Metricool (https://metricool.com/)
